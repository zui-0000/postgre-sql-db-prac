# OSS-DB Silver 学習ノート

OSS-DB Exam Silver（Ver.3.0）の合格を目指して、出題範囲ごとに内容をまとめる。PostgreSQL を実際に動かしながら学ぶ。

- 試験の概要: [00-試験概要](00-試験概要.md)
- 学習環境: PostgreSQL **18.6**（Docker Compose）。手順は [01 環境構築](../../docs/01-環境構築.md)

## 方針

- **最新の安定版（18.6）で学ぶ。** 試験の基準は PostgreSQL 12〜14 なので、バージョンによる違いは各章の「⚠️ 試験と最新版の違い」に書く。
- **手順だけでなく「なぜそうなるのか」を書く。**
- **サーバーの停止やリカバリは sandbox コンテナで試す。** 普段の SQL 操作は db コンテナで行う（違いは環境構築の章で説明する）。

## 各章の構成

| 見出し | 内容 |
| --- | --- |
| 出題範囲 | 公式の「主要な知識範囲」と「重要な用語、コマンド、パラメータなど」 |
| 学習メモ | 調べたこと、試したこと、なぜそうなるのか |
| ⚠️ 試験と最新版の違い | 試験の基準（PG 12〜14）と学習環境（PG 18.6）で挙動が違う点 |
| 確認問題 | 自分で解いて理解を確かめる問題。選択式だけでなく、入力形式と「全て選択」形式も混ぜる（理由は [試験概要](00-試験概要.md#出題形式の補足)） |
